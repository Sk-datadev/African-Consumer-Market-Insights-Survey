# banking-survey-data-cleaning
Cleaning and standardization of a multi-country banking survey (3,264 responses, 38 variables) using Excel and Python/pandas — handling duplicate respondents, split question columns, and mixed English/French responses.
## Objectives

- Clean and prepare raw survey data for analysis.
- Remove duplicate columns and respondent records.
- Handle conditional missing values.
- Standardize text responses and remove bilingual inconsistencies.
- Prepare the dataset for PivotTable and statistical analysis.
- Perform descriptive and inferential statistical analysis.
- Automate the data cleaning workflow using Python.

  ## Tools & Technologies

- **Python**
- **Pandas** – Data cleaning and manipulation
- **Excel** – Initial data inspection and statistical analysis
- **Jupyter Notebook** – Python development environment
- **GitHub** – Project documentation and version control

  ## Dataset

The raw dataset contained:

- **3,263 responses**
- **38 columns**
- Survey responses covering demographics, employment, education, banking, satisfaction, and other socioeconomic characteristics.

The dataset required cleaning before it could be reliably used for summarization and statistical analysis.
